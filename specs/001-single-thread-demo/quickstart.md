# Quickstart: التحقق من الخيط الواحد

**Plan**: [plan.md](plan.md) · دليل تحقق، لا تنفيذ. الأوامر تُكتب نهائيًا في `tasks.md` بعد بناء الأدوات؛ هنا السيناريوهات والنتائج المتوقعة.

## المتطلبات

- Windows 11، Python 3.11+، Node.js 24.
- متغيرات بيئة (لا قيم افتراضية؛ الإقلاع يفشل بدونها): `NOOR_DATA_DIR` · `NOOR_EXCHANGE_DIR` (كلاهما خارج المستودع) · `NOOR_SECRET_KEY` · كلمات مرور الحسابات المصطنعة الأربعة (مدير العروض، معتمِد المراجعة، عضو، عرض).
- العينة `samples/synthetic/tender-001/` مكتملة بخط فريق الهندسة، ومعها `RIGHTS.md`.
- لا اتصال شبكي لازم. الاستماع على `127.0.0.1:5310`.

## الفحوص الآلية

- اختبار e2e للخيط على العينة مع منع الشبكة الخارجية.
- اختبار التفويض على كل مسارات Flask المسجلة.
- اختبارات العقود الستة (مُنتِج ومستهلك وحالات الرفض) — [contracts/README.md](contracts/README.md).
- فحص أسرار ومسارات وبيانات حقيقية على الفرق والتاريخ قبل كل commit.
