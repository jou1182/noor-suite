# قوائم الوظائف المعتمدة لكل منصة (FR-010)

بنود المواصفة **حرفيًا** هي معيار القبول، ولا يُحذف بند إلا بتحديث `spec.md` أولًا (المبدأ XI). البنود المضافة من الخطة معلَّمة **(+خطة)** وتحتاج اعتماد م. يوسف (§13: «اعتماد قائمة FR-010 بعد أن تضيف الخطة بنودها»). لكل بند: معرّف، وخطوة تحقق على بيانات مصطنعة، ونتيجة (اجتاز / لم يجتز / محجوب) بصورة (SC-002).

## radar

| المعرّف | البند | التحقق |
|---|---|---|

| RAD-F02 | بحث بالرقم | رقم مرجع مصطنع ⇒ نتيجة واحدة |
| RAD-F03 | بحث بالجهة | جهة مصطنعة ⇒ منافساتها فقط |
| RAD-F04 | بحث بالحالة | كل حالة في البيانات ⇒ عدد صحيح |
| RAD-F05 | بحث بالنوع | نوع ⇒ منافساته فقط |
| RAD-F06 | بحث بالتاريخ | نطاق تاريخ ⇒ المنافسات داخله فقط |
| RAD-F07 | التصنيفات والأنشطة | عرض التصنيف ونشاطه لمنافسة |
| RAD-F08 | حفظ بحث واسترجاعه | حفظ ⇒ خروج ⇒ دخول ⇒ استرجاع |
| RAD-F09 | لوحة القيادة | أرقامها تطابق عدّ القاعدة المصطنعة |
| RAD-F10 | إرسال مرشَّح إلى NMIS | 001 US1 (W1) |
| RAD-F11 (+خطة) | بيان عمر البيانات ومصدرها ظاهر (RAD-07) | تاريخ آخر تحديث للقاعدة المصطنعة ظاهر |
| RAD-F12 (+خطة) | المزامنة الحية والتنزيل معطّلان | الأزرار غائبة أو ترفض برسالة، ولا اتصال (SC-004) |
